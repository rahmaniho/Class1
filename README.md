# مدرسه‌ی من | کلاس اول

یک وب‌اپ فارسی و راست‌چین برای آموزش کامل پایه‌ی اول دبستان: **ریاضی، فارسی و علوم**.
ویژه‌ی کودکان ۶ تا ۷ ساله، با تمرین‌های تعاملی، بازی‌های آموزشی، شنیدن صدای حروف و پیگیری پیشرفت.

## اجرا

بدون هیچ ابزار ساخت (build) اجرا می‌شود — کافی است `index.html` را در مرورگر باز کنید، یا یک سرور ایستا بگیرید:

```bash
python3 -m http.server 8000
# سپس http://localhost:8000 را باز کنید
```

## دانلودِ نسخه‌ی قابلِ نصب

برای آیفون و آی‌پد: در Safari باز کنید ← اشتراک‌گذاری ← «افزودن به صفحه‌ی اصلی».
راهنمای کامل و نحوه‌ی ساختِ دستی در [DOWNLOAD.md](DOWNLOAD.md).

## ساختار

| فایل | نقش |
| --- | --- |
| `index.html` | نقطه‌ی ورود |
| `styles.css` | سامانه‌ی طراحی «کاغذِ جان‌دار» (کاغذ گرم، سایه‌های تخت، RTL) |
| `data.js` | سرفصل‌ها و محتوای آموزشی (۳۹ درس، بیش از ۱۰۰ تمرین) |
| `app.js` | روتر، موتور فعالیت‌ها، تصویرسازی SVG و ذخیره‌ی پیشرفت |
| `images/` | تصویرسازی‌های کاغذی موضوع‌ها، بنر خانه و جشن یادگیری |
| `audio/` | صداهای ضبط‌شده‌ی حروف (`letters/`) و کلمه‌ها (`words/`) |

## صدا

دکمه‌های 🔊 کنار حروف و کلمه‌ها، اول فایل صوتی ضبط‌شده از `audio/` را پخش می‌کنند؛ اگر فایل هنوز ساخته نشده باشد، گفتار مرورگر (Web Speech API) جایگزین می‌شود. افزودن فایل‌های تازه فقط با گذاشتن `mp3` در مسیر درست انجام می‌شود؛ نگاشت نام در `app.js` (بخش `AUDIO_FILES`) است.

## بخش‌ها

- **خانه:** درختِ دانش، جزیره‌ی سه موضوع، درس امروز و تمرین‌های سریع
- **درس‌ها:** ریاضی (شمارش تا ۲۰، جمع و تفریق، مقایسه، شکل‌ها، الگو، ساعت، پول) — فارسی (الفبا از «آ» تا «ی»، کلمه‌سازی، خواندن و درک مطلب) — علوم (جانداران، گیاهان، فصل‌ها، آب‌وهوا، نور، صدا، مواد، ایمنی، حواس)
- **بازی‌ها:** باغ شمارش، شکارچی حروف، سازنده‌ی الگو، کارآگاه طبیعت
- **پیشرفت من:** ستاره‌ها و درس‌های تکمیل‌شده (ذخیره روی همان دستگاه)
- **ورود بزرگ‌ترها:** گزارش یادگیری و پیشنهادهای همراهی (با سدِ محاسبه‌ای ساده)

همه‌ی تصویرها SVG درون‌خطی‌اند؛ برای حالت `prefers-reduced-motion` جایگزین بدون حرکت دارد و همه‌ی دکمه‌ها هدف لمسی دست‌کم ۴۸ پیکسلی دارند.
