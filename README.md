## اجرا

بدون هیچ ابزار ساخت (build) اجرا می‌شود — کافی است `index.html` را در مرورگر باز کنید، یا یک سرور ایستا بگیرید:

```bash
python3 -m http.server 8000
# سپس http://localhost:8000 را باز کنید
```

### نصب از مرورگر (PWA)

نسخه‌ی وب را هم می‌شود مثل یک برنامه نصب کرد — بدون فایل APK:

۱. سایت را در **Chrome** (اندروید یا رایانه)، **Edge** یا **Samsung Internet** باز کنید.
۲. دکمه‌ی **«نصب برنامه»** در صفحه‌ی خانه یا صفحه‌ی [نصب](https://class1.karen-soft.ir/#/install) را بزنید؛
   اگر مرورگر دکمه‌ی خودکار نداد، از منوی مرورگر «نصب برنامه / Install app» یا
   «افزودن به صفحه‌ی اصلی» را انتخاب کنید.
۳. در **آیفون و آیپد**، از Safari دکمه‌ی اشتراک‌گذاری و سپس «Add to Home Screen» را بزنید.

پس از نصب، آیکونِ «مدرسه‌ی من» روی صفحه‌ی اصلی می‌آید و برنامه بدون نوار آدرس و
(پس از نخستین باز شدن) بدون اینترنت کار می‌کند. نصبِ PWA به نشانی **https** نیاز دارد.

## ساختار

| فایل | نقش |
| --- | --- |
| `index.html` | نقطه‌ی ورود |
| `styles.css` | سامانه‌ی طراحی «کاغذِ جان‌دار» (کاغذ گرم، سایه‌های تخت، RTL) |
| `data.js` | سرفصل‌ها و محتوای آموزشی (۳۹ درس، بیش از ۱۰۰ تمرین) |
| `app.js` | روتر، موتور فعالیت‌ها، تصویرسازی SVG و ذخیره‌ی پیشرفت |
| `images/` | تصویرسازی‌های کاغذی موضوع‌ها، بنر خانه و جشن یادگیری |
| `audio/` | صداهای ضبط‌شده‌ی حروف (`letters/`)، کلمه‌ها (`words/`)، هدفِ درس‌ها (`objectives/`)، پرسش‌ها (`questions/`)، قصه‌ها (`stories/`) و گفتارِ کاملِ هر درس (`lessons/`) |

## صدا

دکمه‌های 🔊 کنار حروف، کلمه‌ها، هدفِ هر درس و صورتِ هر پرسش، اول فایل صوتی ضبط‌شده را پخش می‌کنند؛ اگر فایل هنوز ساخته نشده باشد، گفتار مرورگر (Web Speech API) جایگزین می‌شود. صدای هدفِ درس‌ها در `audio/objectives/{id}.mp3`، صدای پرسش‌ها در `audio/questions/q-{hash}.mp3` و گفتارِ کاملِ آموزشِ هر درس (همه‌ی گام‌ها با هم) در `audio/lessons/{id}.mp3` است. نگاشت نامِ حروف و کلمه‌ها در `app.js` (بخش `AUDIO_FILES`) و کلیدِ پرسش‌ها با تابع `audioKey` ساخته می‌شود.

## بخش‌ها

- **خانه:** درختِ دانش، جزیره‌ی سه موضوع، درس امروز و تمرین‌های سریع
- **درس‌ها:** هر درس چهار گامِ آموزشِ تصویری دارد (توضیح، تصویر، مثال و جمع‌بندی) و یک دکمه‌ی «شنیدن همه‌ی آموزش»؛ ریاضی (شمارش تا ۲۰، جمع و تفریق، مقایسه، شکل‌ها، الگو، ساعت، پول) — فارسی (الفبا از «آ» تا «ی»، کلمه‌سازی، خواندن و درک مطلب) — علوم (جانداران، گیاهان، فصل‌ها، آب‌وهوا، نور، صدا، مواد، ایمنی، حواس)
- **بازی‌ها:** باغ شمارش، شکارچی حروف، سازنده‌ی الگو، کارآگاه طبیعت
- **پیشرفت من:** ستاره‌ها و درس‌های تکمیل‌شده (ذخیره روی همان دستگاه)
- **ورود بزرگ‌ترها:** گزارش یادگیری و پیشنهادهای همراهی (با سدِ محاسبه‌ای ساده)

همه‌ی تصویرها SVG درون‌خطی‌اند؛ برای حالت `prefers-reduced-motion` جایگزین بدون حرکت دارد و همه‌ی دکمه‌ها هدف لمسی دست‌کم ۴۸ پیکسلی دارند.
